Pourquoi Sierra Chart ?

Sierra Chart est le logiciel de trading utilisé par les professionnels du Market Profile et de l'Order Flow. Pas le plus joli — mais le plus fiable, le plus configurable, et le plus stable.

Trois raisons qui en font le standard :

  • Intégration native CME Denali — Les données de marché les plus fiables, directement depuis la source. Pas de broker intermédiaire qui filtre ou retarde.
  • Market Profile natif — Le TPO Chart est intégré avec une personnalisation complète (couleurs, périodes, Value Area, POC, Initial Balance).
  • Numbers Bars (Footprint) — L'implémentation la plus complète du Footprint Chart : Bid × Ask, delta, imbalances, volume total par niveau.
Le standard

L'outil ne fait pas le trader — mais le mauvais outil le freine

Sierra Chart est austère. Son interface ressemble à un logiciel des années 2000. Mais sous le capot, c'est le moteur le plus puissant du marché pour l'analyse du flux. La forme est secondaire — la fiabilité des données est tout.

Installation et premier lancement

Téléchargement et licence

  1. Téléchargez Sierra Chart sur le site officiel (sierrachart.com)
  2. Installez le logiciel (Windows uniquement, fonctionne sous Wine/Parallels sur Mac)
  3. Créez un compte et choisissez le Package 3 ($46/mois) — c'est celui qui inclut le Market Profile, les Numbers Bars et le CVD
  4. Activez le service de données Denali Exchange — c'est le flux CME natif de Sierra Chart

Connexion aux données

Une fois le package activé, connectez-vous : File > Data/Trade Service Settings. Sélectionnez "SC Data - All Services" et entrez vos identifiants. La connexion est automatique.

Pour les données CME (Futures ES, NQ, CL, etc.), vous devrez accepter les accords d'échange CME. Coût : ~$9/mois pour les non-professionnels (CME Non-Professional Market Data).

Coût total

Sierra Chart Package 3 ($46) + CME Non-Pro ($9) = ~$55/mois. C'est le coût d'un outil professionnel complet. À comparer avec ATAS ($69/mois) ou Bookmap ($49/mois) qui offrent moins de profondeur.

Configurer le Market Profile (TPO Chart)

Le Market Profile dans Sierra Chart s'appelle TPO Profile Chart. Voici la configuration étape par étape :

Créer un nouveau graphique TPO

  1. File > Find Symbol — Tapez le symbole (ex: ESH26.CME pour l'E-mini S&P 500)
  2. Chart > Chart Settings — Dans "Chart Type", sélectionnez "TPO Profile Chart"
  3. Réglez la période TPO sur 30 minutes (standard pour les Futures US)

Paramètres essentiels

Value Area %70%Règle de Steidlmayer (68.2% arrondi)
Display POCActivéPoint of Control — le prix le plus échangé
Display VA LinesActivéValue Area High et Low

Couleurs et lisibilité

Le défaut de Sierra Chart est moche. Personnalisez : fond noir ou gris très foncé, TPO en couleur par période (lettres colorées), POC en trait rouge ou blanc épais, Value Area en zone semi-transparente. La lisibilité prime sur l'esthétique.

Configurer le Volume Profile

Le Volume Profile complète le TPO en montrant le volume réel échangé à chaque niveau de prix (pas le temps passé).

Dans Sierra Chart : Studies > Add Study > Volume by Price. Configurez :

  • VPOC (Volume Point of Control) — Le prix avec le plus grand volume
  • Value Area High/Low — La zone de 70% du volume total
  • Histogramme — Barres horizontales montrant la distribution du volume

Astuce : affichez le TPO et le Volume Profile sur le même graphique, l'un à gauche et l'autre à droite. La convergence entre le POC du TPO et le VPOC est un signal de haute conviction.

Ajouter le Footprint Chart

Le Footprint Chart dans Sierra Chart s'appelle Numbers Bars. C'est l'implémentation la plus complète du marché.

Activation

  1. Chart > Chart Settings > Chart Type — Sélectionnez un graphique en bougies classique (pas TPO)
  2. Studies > Add Study > Numbers Bars Calculated Values
  3. Dans les settings, choisissez le mode "AskVol x BidVol" — c'est le format Footprint standard

Paramètres clés

  • Imbalance Ratio — Réglez sur 300% (3:1). C'est le seuil standard pour détecter les déséquilibres.
  • Couleurs — Ask en vert/bleu, Bid en rouge, imbalances surlignées en couleur vive
  • Delta total — Activez l'affichage du delta cumulé en bas de chaque bougie
  • Volume total — Affichez le volume total par bougie à côté du delta

Les Numbers Bars en détail

Les Numbers Bars de Sierra Chart offrent plusieurs modes d'affichage :

ModeAffichageUtilisation
AskVol x BidVolVolume acheteur × vendeur par niveauFootprint standard — déséquilibres et absorption
DeltaAsk - Bid par niveauPression nette à chaque prix

Pour commencer, utilisez "AskVol x BidVol". C'est le mode le plus lisible et le plus utile pour repérer les imbalances et l'absorption.

Configurer le CVD

Le CVD (Cumulative Volume Delta) trace la somme cumulée de tous les deltas dans le temps. C'est un indicateur de momentum basé sur le flux réel.

Configuration : Studies > Add Study > Cumulative Delta Bars - Volume. Affichez-le dans un sous-graphique séparé sous votre graphique principal.

Paramètres recommandés :

  • Reset period — Daily (reset à chaque session)
  • Display — Barres colorées (vert si delta positif, rouge si négatif)
  • MA overlay — Ajoutez une moyenne mobile 20 périodes pour lisser le signal
Signal clé

La divergence prix/CVD

Si le prix fait de nouveaux plus hauts mais le CVD ne suit pas (divergence baissière), le rallye manque de conviction acheteuse. C'est un des signaux les plus fiables de retournement imminent. L'inverse est vrai pour les divergences haussières.

Le workspace optimal

Un workspace Sierra Chart bien organisé est crucial pour l'efficacité. Voici la disposition recommandée pour un setup à 2 écrans :

Écran 1 — Analyse

  • Gauche — Market Profile TPO (session courante + veille)
  • Centre — Footprint Chart (Numbers Bars) en 5 minutes
  • Bas — CVD en sous-graphique

Écran 2 — Exécution

  • Gauche — DOM (Depth of Market) avec ordres
  • Centre — Graphique en bougies 1 minute (pour le timing)
  • Droite — Time & Sales / Tape

Sauvegardez votre workspace : File > Save Chartbook As. Créez des templates pour chaque marché (ES, NQ, CL) que vous tradez.

Erreurs courantes de configuration

1. Trop d'indicateurs

Sierra Chart permet d'ajouter des centaines d'études. N'en abusez pas. Market Profile + Footprint + CVD + DOM = suffisant. Chaque indicateur supplémentaire ajoute du bruit, pas du signal.

2. Mauvaise période TPO

30 minutes est le standard pour les Futures US. Ne passez pas à 15 minutes ou 1 heure sans raison — vous perdez la comparabilité avec les autres traders et les études historiques.

3. Seuil d'imbalance trop bas

Un seuil de 150% génère trop de faux signaux. Gardez 300% minimum. Mieux vaut moins de signaux mais de meilleure qualité.

4. Ne pas sauvegarder les templates

Sierra Chart peut planter (rarement, mais ça arrive). Sauvegardez vos Chartbooks régulièrement et faites un backup de votre dossier Sierra Chart.

5. Données retardées sans le savoir

Si vous n'avez pas activé les données CME en temps réel, vous tradez avec un retard de 10-15 minutes. Vérifiez : Window > Message Log — si vous voyez "delayed data", activez les données CME Non-Professional.
